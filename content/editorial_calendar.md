## Publishing checklist

Before each post:

1. Re-read the post without the visual and confirm it stands alone.
2. Check every number against the current mart output.
3. Confirm the glossary explains only the terms used in that episode.
4. Export the visual at 4:5 and inspect it on mobile.
5. Keep the simulation disclosure unchanged.
6. Approve the post copy and visual separately.

After each post:

1. Answer substantive comments with the same evidence boundary used in the project.
2. Record questions that could improve a later episode.
3. Avoid changing an approved metric definition in response to engagement.
4. Review reach, profile views, relevant connection requests and conversations after 48 hours.
